Understand English with English you already know.

Select a word, phrase, or sentence on a webpage. Get an English explanation and an example at your **A1–C2 reading level**, then keep reading.

## What it does

- Explains unfamiliar English directly on the page.
- Offers offline reading samples to help you choose a level.
- Supports Gemini, Claude, OpenAI, DeepSeek, Grok and custom OpenAI-compatible services.

## Get started

Chrome Web Store link coming soon. For now:

1. Download and unzip this repository. Open `chrome://extensions/`, enable **Developer mode**, choose **Load unpacked**, and select the folder containing `manifest.json`.
2. In Settings, choose your reading level, connect a model service with your API key, and save.
3. Select English text on a webpage and click the **book icon**.

Free and open source; model providers may charge for API usage. Keys stay in local browser storage. Selected text is sent to your chosen provider when you request an explanation.

The interface supports eight languages. Reading samples and explanations stay in English.
