Comprenez l’anglais avec l’anglais que vous connaissez déjà.

Sélectionnez un mot, une expression ou une phrase sur une page. Obtenez une explication en anglais et un exemple adaptés à votre **niveau de lecture A1–C2**, puis poursuivez votre lecture.

## Fonctionnalités

- Des explications sur la page que vous lisez.
- Des textes hors ligne pour choisir un niveau adapté.
- Gemini, Claude, OpenAI, DeepSeek, Grok et des services personnalisés compatibles avec OpenAI.

## Premiers pas

Le lien vers le Chrome Web Store sera disponible prochainement. Pour le moment :

1. Téléchargez et décompressez ce dépôt. Ouvrez `chrome://extensions/`, activez le **Mode développeur**, puis cliquez sur **Charger l’extension non empaquetée**. Choisissez le dossier contenant `manifest.json`.
2. Dans les paramètres, choisissez votre niveau, configurez un service de modèles avec votre clé API et enregistrez.
3. Sélectionnez du texte anglais sur une page et cliquez sur l’**icône du livre**.

L’extension est gratuite et open source. Les fournisseurs peuvent facturer l’utilisation de leur API. Les clés restent dans le stockage local du navigateur ; le texte sélectionné est envoyé au fournisseur choisi lorsque vous demandez une explication.

L’interface propose huit langues. Les textes de lecture et les explications restent en anglais.
