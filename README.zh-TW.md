在網頁上選取單字、片語或句子，取得符合你 **A1–C2 閱讀程度**的英文解釋與例句，繼續讀下去。

## 它能做什麼

- 直接在原網頁解釋不熟悉的英文。
- 提供離線試讀文章，幫助你選擇適合的程度。
- 支援 Gemini、Claude、OpenAI、DeepSeek、Grok 和自訂 OpenAI 相容服務。

## 開始使用

Chrome 線上應用程式商店連結即將提供，目前可從原始碼安裝：

1. 下載並解壓縮本儲存庫。開啟 `chrome://extensions/`，啟用**開發人員模式**，點選**載入未封裝項目**，選擇包含 `manifest.json` 的資料夾。
2. 在設定中選擇閱讀程度，填入模型服務的 API Key 並儲存。
3. 在網頁上選取英文，點選旁邊的**書本圖示**。

擴充功能免費且開放原始碼，模型服務可能收取 API 費用。Key 儲存在本機瀏覽器；請求解釋時，選取的文字會傳送給你選擇的服務商。

介面支援八種語言，試讀文章和解釋維持英文。
