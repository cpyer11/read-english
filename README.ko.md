## 주요 기능

- 읽고 있는 페이지에서 바로 영어 설명을 확인하세요.
- 오프라인 읽기 지문으로 편안하게 이해할 수 있는 수준을 선택하세요.
- Gemini, Claude, OpenAI, DeepSeek, Grok 및 사용자 지정 OpenAI 호환 서비스를 지원합니다.

## 시작하기

Chrome 웹 스토어 링크는 추후 제공됩니다. 현재는 소스 코드로 설치할 수 있습니다.

1. 이 저장소를 다운로드하고 압축을 푸세요. `chrome://extensions/`에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택한 뒤, `manifest.json`이 있는 폴더를 지정하세요.
2. 설정에서 읽기 수준을 선택하고 모델 서비스의 API 키를 입력한 뒤 저장하세요.
3. 웹페이지에서 영어를 선택하고 **책 아이콘**을 클릭하세요.

확장 프로그램은 무료 오픈 소스입니다. 모델 제공업체에서 API 사용료를 청구할 수 있습니다. 키는 로컬 브라우저에 저장되며, 설명을 요청하면 선택한 텍스트가 지정한 제공업체로 전송됩니다.

인터페이스는 8개 언어를 지원합니다. 읽기 지문과 설명은 영어로 제공됩니다.
