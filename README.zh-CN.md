# Read English

[English](README.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português](README.pt-BR.md)

用你已经懂的英文，理解新的英文。

在网页上选中单词、短语或句子，获取符合你 **A1–C2 阅读等级**的英文解释与例句，继续读下去。

## 它能做什么

- 直接在原网页解释不熟悉的英文。
- 提供离线试读文章，帮助你选择合适的等级。
- 支持 Gemini、Claude、OpenAI、DeepSeek、Grok 和自定义 OpenAI 兼容服务。

## 开始使用

Chrome 应用商店链接即将提供，目前可从源码安装：

1. 下载并解压本仓库。打开 `chrome://extensions/`，开启**开发者模式**，点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
2. 在设置中选择阅读等级，填写模型服务的 API Key 并保存。
3. 在网页上选中英文，点击旁边的**书本图标**。

插件免费开源，模型服务可能收取 API 费用。Key 保存在本地浏览器；请求解释时，选中的文本会发送给你选择的服务商。

界面支持八种语言，试读文章和解释保持英文。
