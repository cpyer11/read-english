# Read English

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · **日本語** · [Español](README.es.md) · [Français](README.fr.md) · [Português](README.pt-BR.md)

すでに知っている英語で、新しい英語を理解する。

ウェブページで単語・フレーズ・文を選択すると、**A1–C2 の読解レベル**に合った英語の説明と例文が表示されます。読書の流れを保ちながら読み進められます。

## 主な機能

- 読んでいるページで英語の説明を確認。
- オフラインの試読文で、自分に合うレベルを選択。
- Gemini、Claude、OpenAI、DeepSeek、Grok、カスタムの OpenAI 互換サービスに対応。

## 使い始める

Chrome ウェブストアへのリンクは準備中です。現在はソースコードからインストールできます。

1. このリポジトリをダウンロードして解凍します。`chrome://extensions/` で**デベロッパーモード**を有効にし、**パッケージ化されていない拡張機能を読み込む**から `manifest.json` のあるフォルダを選択します。
2. 設定で読解レベルを選び、モデルサービスの API キーを入力して保存します。
3. ウェブページで英文を選択し、**本のアイコン**をクリックします。

拡張機能は無料のオープンソースです。モデル提供元の API 利用料がかかる場合があります。キーはローカルのブラウザに保存され、説明をリクエストすると選択したテキストが指定の提供元に送信されます。

画面表示は8言語に対応しています。試読文と説明は英語のままです。
