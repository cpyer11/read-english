## Funciones

- Explicaciones de inglés en la misma página.
- Textos sin conexión para elegir un nivel cómodo.
- Gemini, Claude, OpenAI, DeepSeek, Grok y servicios personalizados compatibles con OpenAI.

## Primeros pasos

El enlace a Chrome Web Store estará disponible próximamente. Por ahora:

1. Descarga y descomprime este repositorio. Abre `chrome://extensions/`, activa el **Modo de desarrollador**, pulsa **Cargar descomprimida** y selecciona la carpeta con `manifest.json`.
2. En Configuración, elige tu nivel, conecta un servicio de modelos con tu clave API y guarda los cambios.
3. Selecciona texto en inglés en una página y pulsa el **icono del libro**.

La extensión es gratuita y de código abierto. Los proveedores pueden cobrar por usar su API. Las claves se guardan localmente en el navegador; al pedir una explicación, el texto seleccionado se envía al proveedor elegido.

La interfaz admite ocho idiomas. Los textos de lectura y las explicaciones permanecen en inglés.
